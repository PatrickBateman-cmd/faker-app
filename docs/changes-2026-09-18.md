## Feature: Balance / Reconciliation Set Generator

When `reconciliation_mode=true`, the generation run derives a balances dataset per partition (`partition_date` × group-by keys) from the source transaction dataset:

- **Continuity**: opening balance carries over from the previous partition's closing; opening defaults to `0` on the first day per key
- **Control totals** (transaction-only): `sum_positives`, `sum_negatives`, `record_count`
- **Invariant** per partition: `sum_positives + sum_negatives = closing − opening`
- **Scaling rule** (per spec): `source.rows == days × records_per_day` — validated at generate time
- **Sign handling**: optional `sign_field` + `positive_values` map to positive; otherwise amounts used as-is
